# Firda Software Development Drachten

Welkom bij de GitHub-organisatie van de opleiding **Software Developer van Firda in Drachten**.
Hier werken studenten samen aan echte projecten, op dezelfde manier als in de open-sourcewereld:
met forks, branches, pull requests en code reviews.

## Projecten

| Project | Wat is het? | Talen |
| --- | --- | --- |
| [**aquarium**](https://github.com/Firda-Software-Development-Drachten/aquarium) | Ontwerp een vis in de Vissenmaker en zie hem zwemmen in het Unity-aquarium. | Unity/C#, Python, HTML/CSS, JavaScript |

## Meedoen als student

1. Maak een GitHub-account.
2. Kies een project en lees de `CONTRIBUTING.md` van dat project.
3. Zoek een issue met het label `good first issue` en laat in een reactie weten dat je het oppakt.
4. Fork de repo, maak een branch, doe je wijziging en open een pull request.
5. Een docent reviewt je werk. Verwerk de feedback, en na de merge staat jouw bijdrage erin.

## Wat je hier leert

- Samenwerken met Git en GitHub
- Code lezen en verbeteren die iemand anders heeft geschreven
- Feedback geven en ontvangen in code reviews
- Werken met automatische controles (GitHub Actions)
